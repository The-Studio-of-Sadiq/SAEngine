# Bangla Language Pack for SAEngine

Built-in language pack that shows SAEngine's own screens in Bangla (বাংলা). The rest of the
Code-OSS workbench stays in English. Choose it with **Configure Display Language** and
restart SAEngine.

The files in `translations/` are generated from `build/saengine/i18n/bn/strings.bn.json`;
see `build/saengine/i18n/README.md` for how to translate and regenerate them.
