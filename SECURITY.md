# Private reports and security

## Private reports

GitHub issues are public. If a bug report or feedback involves a client, a site, or a project
you cannot share, e-mail it to the developers instead:

**publicrelations@thestudioofsadiq.tech**

In SAEngine, **Help > Report a Bug** (or **Send Feedback**) with **Send As: Private** writes
this e-mail for you. You see the whole report first, and nothing is sent until you send it from
your mail program. Private reports are not published.

## Security problems

Please do not open a public issue for a security problem. E-mail
**publicrelations@thestudioofsadiq.tech** with the subject "SAEngine security". Include the
version (Help > About), what an attacker could do, and how to reproduce it. We will answer and
agree on a fix and a disclosure date with you.
