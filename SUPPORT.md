# Getting help

| You need... | Go to |
| --- | --- |
| How to install and start | The [wiki](https://github.com/The-Studio-of-Sadiq/SAEngine/wiki): [Installing](https://github.com/The-Studio-of-Sadiq/SAEngine/wiki/Installing), [Getting Started](https://github.com/The-Studio-of-Sadiq/SAEngine/wiki/Getting-Started) |
| How a part of the program works | The [user manual](docs/manual/README.md) and the [FAQ](https://github.com/The-Studio-of-Sadiq/SAEngine/wiki/FAQ) |
| To report a bug or a wrong result | **Help › Report a Bug** in SAEngine, or an [issue](https://github.com/The-Studio-of-Sadiq/SAEngine/issues/new/choose) |
| To suggest a feature | **Help › Send Feedback**, or a *Feature request* issue |
| To ask privately (a client's project, a site, anything confidential) | publicrelations@thestudioofsadiq.tech |
| To report a security problem | See [SECURITY.md](SECURITY.md) |

Issues are public: leave out client names, addresses and confidential project details.

SAEngine is pre-alpha and maintained by a small team, so answers can take a few days. There is
no warranty or guaranteed support: check every result independently before you rely on it.
